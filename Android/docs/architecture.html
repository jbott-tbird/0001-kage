One design definition

ui/theme/DesignTokens.kt defines the light/dark palette, typography, spacing scale, shapes, and component dimensions. Theme.kt applies them to Material 3. Screens use Material themes and shared tokens instead of defining individual palettes.

Durable mock mail

Accounts → Folders → Messages → Attachments. Account removal cascades through the hierarchy. Preferences hold the selected folder, first-run state, attachment policy, offline mode, and preview options.

Three sample accounts include normal folders and custom folders. Sample messages exercise international text, missing fields, long strings, HTML, and attachments. Bodies live in Room; PDFs are cached in private app storage and shared through FileProvider.

Seed data never overwrites user changes on ordinary startup. Room schema exports establish the baseline for explicit migrations.

From prototype to connected mail

  1. IMAP/SMTP transport and provider authentication behind repository contracts.
  2. Secure token storage, MIME parsing and HTML sanitization.
  3. Background sync, folder reconciliation, retries and notifications.
  4. Real attachment import/download, server-side search and scalable paging.
  5. Conversation grouping between v1 and v2; JMAP in v2.

This build operates on local sample data and does not send network email.
